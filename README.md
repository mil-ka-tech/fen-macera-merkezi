# Fen Macera Merkezi

Bu klasör GitHub Pages için hazırlandı.

## İçerik
- `index.html` → ana sayfa
- `ay-gorevi/index.html` → Ay Görevi oyunu

## GitHub Pages ile yayınlama
1. GitHub'da yeni bir repository oluştur.
2. Bu klasörün içindeki dosyaları repository'nin ana dizinine yükle.
3. Repository > Settings > Pages bölümüne gir.
4. Source olarak `Deploy from a branch` seç.
5. Branch olarak `main`, klasör olarak `/ (root)` seç ve Save de.
6. Birkaç dakika sonra GitHub sana yayın adresini verir.

Not: Ay Gözlem Günlüğü kayıtları şu an tarayıcının `localStorage` alanında saklanır. Aynı cihaz ve tarayıcıda kalır; başka cihaza otomatik taşınmaz.
